# Priyansh's Portfolio Website

This is a beginner-friendly personal portfolio website made with only HTML and CSS. It is ready to edit, open locally, and publish for free.

## Files

- `index.html` — all visible text, sections, and links.
- `styles.css` — colours, layout, mobile responsiveness, and design.

## Edit before sharing

Open `index.html` in VS Code or any text editor and replace these placeholders:

1. Change `your.email@example.com` to your real email address in the Contact section.
2. Change each `href="#"` next to GitHub, LinkedIn, and Instagram to your real profile link. Example: `href="https://github.com/your-username"`.
3. Replace a planned project card only after you finish a real project. Add its name, a short description, tools used, GitHub link, and live link.
4. Update the skills section whenever your level changes. Keeping it honest makes your portfolio stronger.

## Run it on your computer

1. Open the `priyansh-portfolio` folder.
2. Double-click `index.html`.
3. It will open in your web browser.
4. After editing, save the file and refresh the browser to see the changes.

If you use VS Code, you can also install the **Live Server** extension and select **Go Live**. This automatically refreshes the website after you save.

## Publish free with GitHub Pages

1. Create a free account at [github.com](https://github.com) if you do not have one.
2. Create a new **public** repository. A simple name is `priyansh-portfolio`.
3. Upload `index.html` and `styles.css` from this folder to the repository's main page. Do not place them inside another folder.
4. In the repository, open **Settings** → **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait a few minutes. GitHub will show your public website address in the Pages settings. It normally looks like `https://your-github-username.github.io/priyansh-portfolio/`.

Every time you update and upload these files to the `main` branch, GitHub Pages updates the live website automatically.
